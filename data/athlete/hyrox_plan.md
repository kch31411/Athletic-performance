# HYROX 오픈 싱글 준비 계획

- 목표 대회: 2027년 5월 중순 (정확한 날짜 미정) — 2026-11-26 기준 약 24주
- 출발점: 예상 1:28:22 (범위 1:21:53~1:35:22), HYROX 기록 0건 → `python -m coach hyrox` 로 갱신 확인
- 이 문서의 숫자는 엔진 계산값이고, 주차별 구성은 일반적인 훈련 원칙에 따른 제안이다. 기록이 쌓이면 우선순위를 다시 본다.

## 어디서 시간이 나오나 (엔진 민감도, 2026-11-26)

| 개선 | 줄어드는 시간 |
|---|---|
| 러닝 5% 빨라짐 | 약 2분 35초 |
| 월볼 10% | 38초 |
| 슬레드 풀 10% | 32초 |
| 버피 브로드 점프 / 로잉 / 스키 각 10% | 27~28초씩 |
| 샌드백 런지 10% | 26초 |
| 슬레드 푸쉬 10% | 22초 |
| 파머스 캐리 10% | 14초 |

러닝 5% + 슬레드 두 개를 평균 수준까지 → 약 1:24:30.
레이스의 절반이 러닝이라 러닝이 가장 큰 지렛대이고, 평균 대비 가장 뒤처진 곳은 슬레드 풀(+46초)·푸쉬(+29초)다.

## 1단계 — 기준 측정과 러닝 기반 (지금 ~ 12월 말)

모델에 HYROX 기록이 없어서 먼저 재야 한다. 주 1~2개씩, 수업 전후나 금요일 HYROX 수업 때.

- [ ] 슬레드 푸쉬 50m @152kg (쌩쌩할 때, 시간)
- [ ] 슬레드 풀 50m @103kg (쌩쌩할 때, 시간)
- [ ] 월볼 6kg 100개 시간 (지금은 30개씩 끊어서 함 — 몇 번에 끊었는지도)
- [ ] 로잉 1000m 전력, 스키 1000m 전력
- [ ] 러닝 5km 또는 10km 기록
- [ ] (기구가 되면) 버피 브로드 점프 80m, 파머스 캐리 200m @24kg×2, 샌드백 런지 100m @20kg

러닝: 수업 외에 주 2회 추가 — 편한 페이스 6~8km 1회, 1km 반복(대회 목표 페이스 5:20~5:30/km, 4~6회) 1회.

## 2단계 — 약점 보강 (1 ~ 2월)

- 슬레드: 주 1회, 대회 무게로 짧게 여러 번(예: 25m × 4~6) → 점차 50m 연속.
- 슬레드에 쓰이는 근력: 하체·등 스트렝스 수업(WEIGHT)을 주 1회 넣는 것을 고려.
- 월볼: 끊는 단위를 30 → 40~50개로. 100개를 3번 안에.
- 러닝 뒤 스테이션: 1km 달리고 바로 스테이션 1개를 붙이는 조합을 주 1회.
- 러닝은 주 2회 유지, 긴 러닝을 10~12km 까지.

## 3단계 — 대회 특화 (3 ~ 4월)

- 하프 시뮬레이션(러닝 4 + 스테이션 4) 2~3회, 대회 3~4주 전에 풀 시뮬레이션 1회 → `log_hyrox_race`.
- 구간별 목표 페이스 확정(그 시점의 `python -m coach hyrox` 기준), 이동 구간 연습.

## 테이퍼 (대회 전 10~14일)

- 강도는 유지하되 양을 절반으로. 마지막 주는 짧은 대회 페이스 자극만.
